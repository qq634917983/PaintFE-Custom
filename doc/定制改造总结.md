# PaintFE Custom 定制改造总结

本文档记录 PaintFE Custom 相对上游版本完成的主要改造，重点是让界面和交互更贴近 Photoshop 用户习惯，同时修复粘贴、像素移动、缩放和图层缓存相关问题。

## 1. 工作区与整体 UI

- 将工作区重构为更接近 Photoshop 的固定布局：顶部菜单与工具选项、左侧工具栏、中央画布、右侧检查器以及底部状态栏。
- 工具选项栏融入顶部区域，不再以视觉上独立的组件出现。
- 右侧检查器集中放置导航器、图层、颜色和历史记录等常用面板。
- 底部状态栏显示画布尺寸、缩放比例、当前图层和工具提示。
- 调整面板间距、背景色和尺寸，使各区域的层级和边界更加统一。

## 2. 左侧工具栏

- 工具按钮改为单列垂直排列。
- 工具栏宽度缩减为略宽于按钮，减少对画布空间的占用。
- 工具较多时支持垂直滚动，但隐藏滚动条。
- 默认工具顺序调整为：
  1. 移动
  2. 矩形选取
  3. 椭圆选取
  4. 魔术棒
  5. 移动选区
- 在“首选项”中增加“工具栏”标签页，允许用户自定义工具排列顺序并恢复默认顺序。
- 工具顺序写入用户设置，重启后继续保留。

## 3. 工具选项与变换输入

- 工具选项统一显示在顶部工具选项栏。
- 为粘贴和像素移动变换增加可手动编辑的参数：
  - `X`：水平位置
  - `Y`：垂直位置
  - `W`：宽度
  - `H`：高度
  - 角度：旋转角度
- 鼠标拖拽和数值输入使用同一套变换状态，修改后会同步反映到画布。
- 像素移动过程中切换到其他工具会自动确认，相当于按下 Enter，不再强制用户额外确认。

## 4. 复制、粘贴与像素移动

### 普通粘贴

- 复制选区后粘贴时，立即创建新的透明图层。
- 粘贴像素直接写入新图层，不再停留在必须按 Enter 才会落层的浮动状态。
- 内部复制保留原始文档坐标，因此默认粘贴到原位置。
- 外部剪贴板图片没有源坐标时放置在画布中心。
- 粘贴位置不再依赖鼠标是否位于画布内，也不会跟随鼠标位置变化。

### 像素移动

- 启动“像素移动”时，先从源图层提取选区像素。
- 随即创建并激活新的 `Moved Pixels` 图层，移动操作在该新图层上完成。
- 切换其他工具时自动提交当前移动。
- 按 Esc 取消时恢复操作前快照，同时移除自动创建的新图层。
- 操作被记录为一次可撤销的历史记录。

### 图层显示一致性

- 插入新图层后主动清除按图层索引缓存的 GPU 纹理。
- 同时清理图层缩略图缓存，避免新旧图层索引错位。
- 修复“新图层已经创建，但画面或缩略图看起来仍属于旧图层”的问题。

## 5. 导航器与右侧面板

- 修复 Preview/导航器无法正常显示的问题。
- 导航器优先直接使用当前 GPU 合成纹理。
- GPU 纹理暂不可用时，从已有 CPU 合成缓冲生成降采样预览作为回退。
- 在导航器上显示当前视口范围，并支持点击或拖动定位画布。
- 增加缩小、放大和实际大小控制。

## 6. 中文本地化

- 补充右侧面板、历史记录、导航器、图层、工具栏设置和工具提示等界面的中文文本。
- 同步增加对应英文键值，避免语言切换后出现缺失键。
- 历史记录中的常用操作名称改为可本地化显示。
- 本次为 `en` 和 `zh-CN` 分别增加约 71 个界面文本键。

## 7. 缩放性能与范围

### 修复重复滚轮处理

- 原实现会在两个更新阶段处理同一个滚轮事件，导致一次滚动被缩放两次。
- 现在统一从原始滚轮事件处理缩放，每个事件只执行一次。
- 对单帧聚合的滚轮输入设置合理跨度，避免积压事件瞬间跳到缩放极限。

### 视图与图像合成解耦

- 缩放和平移现在只修改视图比例、屏幕绘制矩形和视图偏移。
- 缩放不再把画布像素标记为脏数据。
- 缩放跨过纹理过滤阈值时，不再重新执行整张画布的 GPU 图层合成。
- CPU 回退路径不再因为缩放复制并重新上传整张合成图。
- 笔刷预览纹理不会仅因为缩放倍率变化而被销毁重建。
- 只有像素、图层可见性、透明度、混合模式等内容真正改变时才重新合成。

### 缩放范围

- 主画布最小缩放比例由 10% 调整为 1%。
- 滚轮、缩放按钮、缩放工具、区域缩放和项目视图恢复统一使用 1% 下限。
- 最大缩放比例保持 10000%。

## 8. 构建与发布配置

为兼顾日常开发速度和最终发行性能，将构建配置分为两个用途：

### 日常调试

```powershell
cargo run
```

编译最快，适合开发和排查逻辑问题，但运行性能低于优化版本。

### 日常性能测试

```powershell
cargo run --release
```

`release` 配置关闭完整 LTO，使用多个 codegen unit 并启用增量编译，减少反复修改后的等待时间。

### 正式发行包

```powershell
cargo build --profile dist
```

`dist` 配置启用完整 LTO、单 codegen unit 和符号剥离，用于生成最终分发版本。产物位于：

```text
target/dist/PaintFE.exe
```

项目的 `rust-toolchain.toml` 当前固定 Rust 1.93.0，因此普通 `cargo` 命令会自动使用项目指定工具链；本机安装更高版本并不代表该项目会自动切换。

## 9. 主要涉及文件

- `src/app/bootstrap.rs`：粘贴请求、落层位置和立即提交逻辑。
- `src/app/ops/helpers.rs`：粘贴/像素移动提交、历史和缓存失效。
- `src/app/runtime/update/canvas_tail.rs`：Photoshop 风格工作区、导航器和工具切换自动确认。
- `src/app/runtime/update/input_shortcuts.rs`：滚轮缩放和像素移动启动流程。
- `src/app/runtime/update/lifecycle_async.rs`：移除重复滚轮缩放路径。
- `src/canvas/view/core.rs`：视图缩放、GPU 合成解耦及 1% 缩放下限。
- `src/components/layers/*`：图层缩略图及 GPU 缓存一致性。
- `src/config/settings.rs`：可持久化的工具栏顺序设置。
- `src/ui/panels/settings_window.rs`：首选项中的工具栏排序界面。
- `src/ui/panels/tools/*`：工具顺序、选项栏和工具显示行为。
- `locales/en.txt`、`locales/zh-CN.txt`：新增界面本地化文本。
- `Cargo.toml`：日常 release 与正式 dist 构建配置。

## 10. 验证状态

- 已执行 `cargo +1.93.0 fmt --all`。
- 已多次执行 `cargo +1.93.0 check -q`，当前编译检查通过。
- 已针对普通粘贴、新图层像素归属、像素移动新图层、工具切换自动确认、连续滚轮缩放和 1% 缩放下限进行代码路径检查。

## 11. 后续可继续优化

- 为超大画布增加按可见区域绘制的分块 GPU 渲染。
- 为缩小显示生成 mipmap 或多级低分辨率合成缓存。
- 继续补齐尚未覆盖的英文对话框和插件界面翻译。
- 为粘贴、移动像素、工具切换和缩放增加自动化回归测试。
- 增加 Windows 便携版和安装包的自动发布验证。
